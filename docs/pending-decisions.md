## 语料与内容

- 当前本地 C1 摄取已经按中文维基文库转录层 CC BY-SA 4.0 管理。公开再发布前仍须确认发布路径：提供合理署名、许可链接、修改说明和适用改编层的相同方式共享，且把来源数据许可与代码/现代编辑文本许可分开；或者不发布维基转录，改从权利清晰的公版扫描独立转录并保存校勘证据。
- 为 12,354 条接受记录完成近重复与故事实体裁决。当前只有 12,353 条规范化精确文本唯一的 canonical 记录；《太平廣記》“桓邈”两处记录已形成 1 个 exact-duplicate cluster，但跨标题、节本、重复收录、转述和同母题异文仍未处理。确认抽检方案、聚类阈值、人工合并/拆分规则和可回滚日志后，才能对外声称“单篇故事数”。
- 补齐 C1 每条来源页面的 revision/history 归属链，或形成可审计的替代方案。当前 EPUB 文件级哈希已冻结，但逐页 `revision_id`、`revision_timestamp` 与固定链接仍为空。
- 指定一名文本/底本复核者和一名独立文化复核者；成人内容还需安全复核。未完成前，30 份产品主文本均保持 `c3-dev` 与 `production_eligible=false`；30 条后台第二见证也不得进入推荐。
- 复核 C2 主文本遴选账本，尤其是 7 个显式例外。当前“产品主文本”只是演示编辑选择，不得宣传为“最权威版本”或学术定本。
- 当前技术演示采用一个打包确认框；用户明确接受成年、非诊疗、云端处理与敏感内容说明后，3 份成人门主文本也可参与推荐。若进入公开测试，应重新评估是否恢复独立的敏感内容选择。
- 为 30 则详标故事排定双人文化复核；优先处理涉及自尽、殉情、家庭暴力、斩首、药物试验、性别本质化或忠贞规训的主文本。
- C1 产品抽样策略已按技术 Demo 决定：12,353 条 canonical 来源记录全部进入轻量推荐池，不等待逐条审计；唯一精确重复不重复推荐。后续若转向公开生产，再决定故事实体聚类、敏感内容、底本与文化复核流程。180 条旧策展目录中的 150 条 `metadata_only` 研究线索仍不与全文池混用。
