# 梦蝶记 Demo 开发状态

更新时间：2026-08-10

## 当前可体验版本

- 品牌已统一为“梦蝶记”，三阶段为“相遇 / 共谱 / 再演”。首页首次出现“栖蝶”时即说明它是故事向导 AI；弹窗、推荐卡、映射画布和剧场面向用户的主要文案均为简体中文。古籍繁体原文只在显示层转换为简体，底层来源文本保持不变。
- 首页采用月白、黛青、矿物绿、灯火金与朱砂色系，以全屏水墨梦境原画、雾层、蝶影、书页与印记构成新中式视觉线索，并提供慢速呼吸、指针视差和滚动显现。落地页现含可切换完整案例、三阶段功能、五步技术链路、数据口径与体验入口；点击体验后才出现边界确认弹窗，用户只需勾选一个整合确认项。
- 页面只呈现一个统一故事池：当前共 12,383 个可推荐候选。产品界面不区分“预制”“深标”或内部数据层级，选中任一故事后都按同一体验流程整理讲解、映射与剧场内容。

## 相遇：受限混合 RAG 推荐

旧版采用规则检索和确定性排序，不是完整的 RAG。当前版本已经改为受限混合 RAG：

1. DeepSeek 根据用户确认后的经历摘要生成简体/繁体检索词与主题计划。
2. SQLite FTS5/BM25 从来源故事库召回候选，并与编辑故事候选合并。
3. 服务端最多向 DeepSeek 提供 8 个候选，每个候选原文不超过 500 字，用于重排并生成逐卡推荐理由。
4. 模型不可用、超时或输出不合格时，系统自动回退到确定性检索和排序，仍可继续体验。

推荐卡只显示大众题名、来源古籍/卷次、简短故事说明与基于用户分享的推荐理由，不暴露内部数据标签或英文工程字段。

## 共谱：自动映射与对话修改

- 用户选定故事后，DeepSeek 会依据所选原文和用户确认的经历自动生成五节点映射初稿，并补充一个“希望锚点”。画布左侧保留故事情节依据，右侧给出对应的用户经历表达。
- 映照助手已接入 DeepSeek。用户可用自然语言提出修改意图，服务端返回具体节点更新与理由；界面先展示修改预览，再由用户决定是否应用。
- 用户仍可直接编辑、留空、标为不适用或调整节点顺序。模型失败时会生成可编辑的确定性五节点初稿，不把用户锁在错误状态。

## 再演：动态多幕与逐幕生图

- 批准映射后生成 4–7 幕剧本，而非固定三幕；每幕保留来源节点关系、幕题、旁白与舞台调度。
- 每一幕可通过阿里云图像模型生成 16:9 场景图。服务端只接受会话、剧本和幕 ID，从已批准内容构造受限提示词；生成失败或图片失效时，自动显示本地纸影画面，演出不会中断。
- 当前开发机已真实生成并下载验证 PNG。针对本机代理伪地址造成的 TLS 阻断，服务只在普通链路失败后启用受限域名、公网 IPv6、原域名 Host/SNI 与默认证书校验的回退，不修改系统网络设置。
- 幕布可拉开/合上；系统旁白支持播放、暂停、继续与停止；环境音支持静音和音量；录音仅在用户主动授权后保存在当前页面内存，可回放和删除，不上传。

## 当前数据边界

- 统一推荐池共 12,383 个候选：其中 12,353 条来自 6 部开放古籍的已切分来源单篇，另有 30 条内部编辑记录。这个内部差异只用于工程处理，不向体验者展示。
- 来源古籍包括《太平广记》《夷坚志》《阅微草堂笔记》《子不语》《续子不语》《聊斋志异》。当前技术 Demo 将全部来源单篇纳入推荐；尚未完成逐条故事实体归并、近重复人工裁决、敏感内容与文化标注。
- 这是一条本地技术演示链路，不代表 12,383 个条目都已完成文史审校，也不构成临床或心理干预产品。

## 验证结果

- `python -m pytest api/tests -q`：57 passed；27 条提示为既有测试客户端的 httpx 弃用警告。
- `npm.cmd run typecheck`：通过。
- `npm.cmd run test:web -- --run`：9 个文件，35/35 passed。
- `npm.cmd run build`：通过；生成 Vite 生产包。
- 真实 HTTP 纵向链路已验证：DeepSeek 检索计划、候选重排、五节点自动映射、助手节点修改、4–7 幕剧本、阿里云逐幕生图和会话删除均成功返回。
- 桌面与 390×844 移动端已验证首页和单勾选弹窗；完整桌面链路已走通相遇推荐、共谱映射、再演剧场与终幕纪念卡。页面无横向溢出，目标用户界面未发现内部“30 篇”或英文工程标签；终幕来源记录只显示最终批准的五个中文映射节点。

## Demo 仍有的限制

- 模型链路速度受网络与上游服务影响。一轮本地实测中，“检索计划 + 重排 + 自动映射”约耗时 2.5 分钟；其他单步调用可在数十秒内完成，因此当前更适合作为演示而非高并发产品。
- 阿里云返回的图片地址是临时资源；刷新或过期后会回退为本地纸影，需要重新生成。
- 浏览器录音功能已经过实现和自动化测试，但尚未替用户授予真实麦克风权限做设备级听感验收。
- 当前没有对外公开部署、并发压测、用户研究或文化专家复核证据。
